# StudyAL Architecture

StudyAL es una plataforma académica construida con:

- Next.js App Router
- TypeScript
- NextAuth
- Cloudflare Workers/D1/R2
- ALAI como motor central de inteligencia artificial

## Carpetas principales

- `app/`: rutas, páginas y APIs.
- `components/`: interfaz y módulos reutilizables.
- `lib/`: lógica central, ALAI, auth, materiales y storage.
- `cloudflare/`: Workers y D1.
- `scripts/`: scripts mantenibles.
- `archive/`: históricos, backups y exportaciones.
- `docs/`: documentación técnica.
